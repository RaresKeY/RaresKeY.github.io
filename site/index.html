03 / Review instinct

I review the invariant, not just the diff.

High-risk changes rarely fail only where the patch is loudest. I trace the intended behavior through code, persistence, authorization, execution boundaries, and regression coverage.

Read the ATS-friendly version →

    Reconstruct

    State the intended invariant and ownership boundary.

  2. 02
    Trace

    Follow code, state, permissions, persistence, and tests.

  3. 03
    Reproduce

    Separate the PR regression from an existing defect.

  4. 04
    Probe

    Test the smallest safe fix in an isolated lane.
